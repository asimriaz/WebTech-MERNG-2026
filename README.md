Here are the CLOs with **CLO-2** and **CLO-3** swapped:

| **CLO**   | **Course Learning Outcome**                                                                                                                                                                                                                                                    | **Bloom's Level**   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------- |
| **CLO-1** | **Explain** the architecture and core concepts of the MERN stack, including MongoDB, Express.js, React.js, Node.js, RESTful APIs, component-based development, state management, routing, and client-server communication.                                                     | **Understand (C2)** |
| **CLO-2** | **Build** secure backend services using Node.js, Express.js, and MongoDB by designing RESTful APIs, performing CRUD operations, implementing authentication and authorization, validating data, and managing database interactions.                                            | **Apply (C3)**      |
| **CLO-3** | **Develop** responsive and interactive front-end applications using React.js by implementing components, JSX, props, state, hooks, forms, routing, API integration, Context API, and modern UI design principles.                                                              | **Apply (C3)**      |
| **CLO-4** | **Design and deploy** a complete MERN stack web application by integrating the React front end with the Express.js/Node.js backend and MongoDB database, implementing authentication, error handling, testing, optimization, and deployment following industry best practices. | **Create (C6)**     |

This sequence is often more logical pedagogically:

1. **Understand** the MERN architecture.
2. **Build the backend** (Node.js, Express.js, MongoDB).
3. **Develop the frontend** (React.js).
4. **Integrate and deploy** the complete MERN application.
